README - Train_Enable

============================== FRANÇAIS ==============================

Train_Enable est un script simple et léger pour FiveM qui permet d'activer le trafic ferroviaire sur la carte. Il rétablit la présence des trains et des métros pour rendre l'univers de jeu plus vivant.

Fonctionnalités
Activation des pistes ferroviaires 0 et 3.
Activation de l'apparition aléatoire des trains sur la carte.
Configuration native de l'intervalle de variation des rails.
Fonctionnement client léger et propre.

Installation
Placez la ressource dans le dossier resources de votre serveur.
Vérifiez que le nom du dossier est bien train_enable.
Ajoutez la ressource à votre configuration serveur :
ensure train_enable
Redémarrez le serveur ou relancez la ressource.

Fonctionnement
Le script s'exécute automatiquement côté client au démarrage de la ressource. Il force l'activation des lignes de train par défaut de GTA V qui sont normalement désactivées dans l'environnement multijoueur de FiveM.

============================== ENGLISH ===============================

Train_Enable is a simple and lightweight script for FiveM that enables rail traffic on the map. It restores the presence of trains and subways to make the game world more immersive.

Features
Activation of train tracks 0 and 3.
Enables random train spawning across the map.
Native configuration of track variation intervals.
Lightweight and clean client-side behavior.

Installation
Place the resource in your server's resources folder.
Make sure the folder name is train_enable.
Add the resource to your server configuration:
ensure train_enable
Restart the server or restart the resource.

How It Works
The script runs automatically on the client side when the resource starts. It forces the activation of default GTA V train lines that are normally disabled in the FiveM multiplayer environment.
